# Package index

## Tax lots

Functions for accessing PLUTO tax lots and MapPLUTO polygons.

- [`nyc_pluto()`](https://kjhealy.github.io/nycpluto/reference/nyc_pluto.md)
  : Get a lazy table reference to PLUTO tax lots
- [`nyc_pluto_path()`](https://kjhealy.github.io/nycpluto/reference/nyc_pluto_path.md)
  : Get the file path to the PLUTO GeoParquet file
- [`nyc_pluto_to_sf()`](https://kjhealy.github.io/nycpluto/reference/nyc_pluto_to_sf.md)
  : Convert collected PLUTO data to an sf object

## Lookup tables and changes

Code definitions and DCP’s corrections to source data.

- [`nyc_pluto_land_use_df`](https://kjhealy.github.io/nycpluto/reference/nyc_pluto_land_use_df.md)
  : PLUTO land use categories
- [`nyc_pluto_bldg_class_df`](https://kjhealy.github.io/nycpluto/reference/nyc_pluto_bldg_class_df.md)
  : PLUTO building classes
- [`nyc_pluto_changes_df`](https://kjhealy.github.io/nycpluto/reference/nyc_pluto_changes_df.md)
  : PLUTO change file
