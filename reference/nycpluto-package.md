# nycpluto: NYC Primary Land Use Tax Lot Output (PLUTO)

The New York City Department of City Planning Primary Land Use Tax Lot
Output (PLUTO) and MapPLUTO: one record per tax lot with land use,
building, zoning, ownership, and assessed value fields, plus lot
polygons. Data are stored as a GeoParquet file and accessed via
duckplyr. Also includes the PLUTO change file and land use and building
class lookup tables.
